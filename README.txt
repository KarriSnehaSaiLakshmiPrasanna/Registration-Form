STUDENT REGISTRATION SYSTEM - PYTHON FLASK

Requirements:
- Python 3.9 or newer
- Flask

How to run:

1. Extract the ZIP file.
2. Open a terminal/command prompt inside the project folder.
3. Install Flask:

   pip install -r requirements.txt

4. Start the application:

   python app.py

5. Open your browser and visit:

   http://127.0.0.1:5000

The SQLite database file (database.db) is created automatically when
the application is first started.

Project technologies:
- Python
- Flask
- HTML
- CSS
- SQLite
- Jinja2

Note:
This is an educational project. For a production application,
passwords should be securely hashed instead of being stored as plain text.
