🎓 Student Registration System using Python Flask

A simple and responsive **Student Registration System** developed using **Python Flask, HTML, CSS, and SQLite**.

This project provides an easy-to-use registration form where students can enter their personal and academic details. The submitted information is validated and stored in an SQLite database.

---

## 📌 Project Overview

The Student Registration System is a web-based application designed to demonstrate how **Python Flask** can be used to build a dynamic web application with database connectivity.

The application allows users to:

- Enter their personal information
- Select their gender
- Select their course
- Create a password
- Submit the registration form
- Store registration details in an SQLite database
- Receive a confirmation page after successful registration

---

## ✨ Features

- 📝 Student registration form
- 👤 Full name input
- 📧 Email validation
- 📱 Phone number validation
- 📅 Date of birth selection

- 🎓 Course selection
- 🔐 Password validation
